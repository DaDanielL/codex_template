# codex_template

Reusable AI-agent-layer template for Codex-driven projects.

This repository does not contain a demo app. It provides the `.agents/` workflow layer used to create product requirements, generate GitHub issue-ready stories, prime context, plan implementation, implement safely, validate work, and review changes.

Start with [.agents/README.md](.agents/README.md).

For a downstream repo, run `setup-agent-workflow` first to create lightweight agent context docs and the canonical GitHub triage labels. Use `grill-with-docs` next when the project language or feature intent needs clarification.
